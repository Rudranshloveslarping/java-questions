## How to run
Open a terminal in the folder containing the file and run:
```bash
javac FileName.java
java FileName
```

Each file is a separate program. Compile and run one file at a time. `Scanner` programs read input from the terminal.

- `.class` files from the supplied ZIP are not included; they are generated by `javac`.
